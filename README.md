# Rekod Lewat SEMARAK

Sistem rekod pelajar lewat di pintu pagar SMK Mengkarak. Frontend PWA untuk telefon dan tablet, backend Google Apps Script, dan data disimpan dalam Google Sheets.

Sebelum tulis kod, baca [CLAUDE.md](CLAUDE.md). Ia mengandungi tujuan sistem, pengguna, struktur folder, dan peraturan wajib.

## Struktur

- `apps-script/` — kod backend (Apps Script, dipush guna `clasp`)
- `web/` — frontend PWA (dihoskan berasingan)
- `docs/` — dokumen reka bentuk dan panduan guru

## Status

Scaffold sahaja. Kaedah login, hosting frontend, dan format laporan belum diputuskan (lihat CLAUDE.md bahagian 5).
